enter a snippet

Enter a snippet of HTML, XHTML, CSS, MathML, or SVG in the text box. When you click ok, ssc will analyse the snippet and output results in the results window.

For example, you could enter this snippet of HTML:



<HTML>
 <HEAD>
  <TITLE>example snippet</TITLE>
 </HEAD>
 <BODY>
  <H1>
   guid tae see ye
  </H1>
  <P>
   whit a bonnie day
  </P>
 </BODY>
</HTML>

If you do so, you will get a couple of warnings, including that the snippet above doesn’t define a default language. Now, you will look at the text and be able to tell, instantly, that it’s written in Scots, but a browser can’t work out that kind of thing, so the HTML should tell it so.

There may be other issues reported as well, it depends on how you’ve configured ssc.

A snippet should be short, no more than around a thousand characters (the exact limit depends on a number of factors). If you want to test anything larger, put it in a file and initiate a site test.
