spelling

This panel controls spell checks. SSC doesn’t check spelling itself, it uses a library. On Windows, it uses the standard Windows spelling library, whereas it uses hunspell under the various unii.

checkboxen

There are a number of options:

  • check spelling, which speaks for itself;
  • check casing, which is particularly important in certain languages;
  • use ICU, the International Components for Unicode, which can improve the quality of spell checks, amongst other things.

files of valid words

Use this set of controls to specify files containing lists of additional valid words.
