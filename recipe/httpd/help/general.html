general

the general panel

This panel is a smorgasbord of miscellaneous settings that don’t belong in another panel.

verify

Two of the three verify options are for class verification.

  • ‘styled classes’ verifies STYLE attributes;
  • ‘every class’ verifies that class values, beyond microformat settings, are declared in CSS in STYLE attributes or CSS files;
  • the completely independent RDFa option lets SSC verify RDFa files. This is not a complete verification of RDFa files, but will identify many issues, and allows SSC to use the information in RDFa files to verify ontology content.

ignore version control files

Selecting ‘ignore version control files’ tells SSC to ignore the files that version control products may litter across HTML source. For example, the popular and appropriately named git version control system often creates .git and .gitignore, among others.

At the time of writing, the full list of files and folders ignored is:

  • .bazaar
  • .bk
  • CVS
  • .cvsignore
  • _darcs
  • .fslckout
  • .git
  • .gitattributes
  • .gitignore
  • .gitmodules
  • .monotone
  • .pijul
  • RCS
  • SCCS
  • .svn

To view the current list of ignored files for your version of SSC, consult the source code.

limit threads to

If SSC was built to be multithreaded, system resource contraints may make it necessary to limit the amount of threads it uses, by settings ‘limit threads to’ an appropriate number. Setting this value to zero tells SSC to use its own judgement.

This option does not appear when SSC is built to not use threading.

ignore these extensions

A file encountered when scanning the site which has one of these extensions will be ignored.

maximum file size

SSC will refuse to process any file which is larger than the specified maximum file size.
