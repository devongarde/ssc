configuration

The settings dialogue consists of a number of panels, and options to load and/or save settings.

panels

The panels are:

  1. summary of settings
  2. HTML et al, corpus
  3. CSS
  4. root, output
  5. bits / bobs
  6. links
  7. nitpicks
  8. onologies
  9. shadow, deduplicate, resolve
  10. spelling (in some builds of ssc)
  11. server side includes
  12. statistics, reports
  13. validation, virtual

To go to a particular panel, select it from the drop down at the top of the dialogue.

common content

configuration files

Underneath every panel are buttons to store settings in and load settings from configuration files. To save your settings, select Save or Save As… as appropriate. To load settings, click Open….

standard buttons

In order to keep users asleep, the help, OK and cancel buttons, common to every panel, behave in the usual way.
