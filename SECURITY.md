# Security Policy

## Supported Versions

SSC is pre-alpha software under active development. There is not (yet) a stable version, let alone a release version.
Thus, in effect, nothing is currently supported. However, any vulnerability report will be gladly received and,
hopefully, quickly addressed.

Until a release version becomes available, it is strongly recommended that you do not use SSC to analyse untrusted content.

## Reporting a Vulnerability

Kindly email a detailed report, including full reproduction steps, to devongarde@me.com, with your full contact details and,
for verification purposes, appropriate references. Thank you in advance for doing so.
