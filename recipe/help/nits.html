nits panel

This panel is part of the Settings Dialogue. It allows you to control what nits are reported, and how.

Output verbosity

All nits with a lower priority that Output verbosity are ignored.

Output file format

You can chose your preferred format of nit output, either the predefined HTML, SPEC, TEST, TEXT, or XHTML, or select an output format definition of your own by choosing bespoke and selecting the file in the template file field. Examples of templates can be found in the source.

individual nit severity

SSC can produce many different nits, at many different severities. You may disagree with SSC’s default severity, so you can change it here. Select the nit from the list box, then select your preferred nit level from the radio buttons below.

checkboxen

output nit IDs

Nit ids are used to control particular nits from the command line, and in testing. If you might want to use them, select Output nit ids.

do not repeat nits

In certain circumstances, certain nits may be repeated. The repeated nits may contain additional information, but also can produce a lot of extra low value output. If you do not wish to see these repeats, on the same problematic piece of code, then select do not repeat nits.
